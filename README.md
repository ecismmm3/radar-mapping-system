# radar-mapping-system
Mini radar mapping system using an ultrasonic sensor for a hackathon.

- Joystick Mode: Sensor angle controlled directly by joystick in real time
- Panning Mode: Sensor pans in direction of joystick
- Visualization tool in Java that maps object shapes and distance in real time
- Displays current mode and object distance
- Modes toggled w/ button, indicated w/ LEDs
